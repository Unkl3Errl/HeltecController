# Support

## Start here

Use the newest release and review the main [`README.md`](README.md) before
opening an issue. For connection or flashing problems, record:

- controller version and Android version;
- phone model and whether a powered OTG hub is involved;
- board model, firmware name, and reported firmware version;
- USB, Bluetooth, BruceNet, or GhostNet transport;
- the exact error and the smallest safe steps that reproduce it.

Do not post passwords, signing data, API keys, precise location history, device
identifiers, or capture contents. Storage-transfer traffic is intentionally
hidden from the interactive console; diagnostic logs should be limited to the
relevant connection or command failure.

## Where to ask

- Open a GitHub issue for reproducible controller, flashing, transport, or
  Android-backed-storage bugs.
- Use the upstream Bruce, GhostESP, or ESP32 Marauder project for behavior that
  also occurs in its unmodified firmware.
- Use the private process in [`SECURITY.md`](SECURITY.md) for vulnerabilities.

This is a community project and does not provide an emergency response or a
guaranteed support time. Radio and network features must be used only on
systems and spectrum you own or are explicitly authorized to test.
